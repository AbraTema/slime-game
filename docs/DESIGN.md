# Slime Game — дизайн тестового уровня

Детский платформер для **Яндекс Игр** (браузер, ПК). Маленький рыцарь бьёт цветных слаймов в уютном подземелье.

## Платформа и техника
- Движок **Phaser 3** (локально в архиве, без CDN). Разрешение 256×144, масштаб ×5 (1280×720), пиксель-арт без сглаживания.
- SDK Яндекс Игр: инициализация по документации, `LoadingAPI.ready()` при показе стартового экрана, `i18n.lang` на старте (п. 2.14), пауза звука при сворачивании вкладки (п. 1.3).
- Язык: только русский. Реклама и облачные сохранения — не в тестовом уровне.
- Сборка: ZIP с `index.html` в корне.

## Визуал (концепты: `docs/concepts/`, генератор: `tools/concepts.py`)
- Локация «Янтарь»: тёплый коричневый камень, мох, много свисающей зелени, факелы с тёплым светом, светящиеся грибы.
- Рыцарь — вариант A: стройный, пропорции человека, с руками; серебро, красное перо, синий плащ.
- Слаймы: маленькие (10×8), с хохолком, без румянца — зелёный, розовый, фиолетовый.
- Мини-босс: золотой Король-слайм в короне.
- Вся графика рисуется кодом (лицензионно чисто), позже заменяема.

## Геймплей
- Управление: ←/→ и A/D — ходьба, пробел и W — прыжок, X и J — меч. Подсказка с клавишами при старте.
- Атака: только меч (архитектура атак расширяемая — прыжок сверху и др. позже).
- 3 сердечка, мигание/неуязвимость после удара. Сердечки кончились → возрождение на последнем флажке-чекпоинте, побеждённые слаймы не возвращаются. Без «Game Over».
- Ямы не смертельны: −1 сердечко и рыцарь возвращается на край.
- Слаймы (урон касанием, 1 удар): зелёный ползает; розовый подпрыгивает к игроку; фиолетовый делится на 2 мини-слайма.
- Кристаллы цвета слайма выпадают при победе + тайники; ~1/5 шанс сердечка, если рыцарь ранен.
- Король-слайм: арена в конце, прыжки с ударной волной (перепрыгнуть), призыв 2 мини-слаймов, 6–8 ударов, полоска здоровья. После победы — сундук/дверь.

## Уровень (2–3 минуты, слева направо)
1. Вводный коридор: 2–3 зелёных слайма.
2. Зона платформ: все три цвета, ~10–12 слаймов.
3. Арена Короля-слайма.
Между зонами — 2 флажка-чекпоинта.

## Экраны и звук
- Старт: название, рыцарь, кнопка «Играть» (разблокирует звук) → подсказка → уровень → «Победа!» (кристаллы, до 3 звёзд, «Ещё раз»).
- Пауза на Esc, кнопка звука в углу.
- Музыка и звуки генерируются кодом через Web Audio (лёгкий 8-битный луп, прыжок, удар, «чпок»).
